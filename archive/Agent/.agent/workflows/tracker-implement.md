# Tracker Implement Workflow (Antigravity)

Follow `AGENTS-IMPLEMENT.md`, `implementation-plan-template.md`, and
`implementation-rules.md` at the agent kit root in full.

Shared invoke summary: `wrappers/tracker-implement.body.md`.

## Trigger

**implement NT-002**, **fix NT-002**, **plan NT-002**, **approve plan NT-002**,
**implement from tracker &lt;path&gt; §&lt;section&gt;**, **resume implement**

## Mandatory phases (do not skip)

1. Intake
2. Current state (NOW) — what code shows today
3. Spec state (DOCUMENT) — what tracker requires
4. Gap analysis — NOW vs DOCUMENT table
5. Implementation plan — **STOP for user approval**
6. Implement — step by step after approval
7. Verify — tests and acceptance criteria
8. Close — mark fixed, summary

No application code changes before Phase 5 approval.
